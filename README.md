# 99 Bottles of OOP - JavaScript Implementation

This repository contains a JavaScript implementation of the 99 Bottles song from the book "99 Bottles of OOP" by Sandi Metz and Katrina Owen.

![Book Cover](https://images.squarespace-cdn.com/content/v1/537c0374e4b0f52ed92942e6/1594023663574-MQGPRREI5LXGW61APBLF/image-asset.jpeg?format=300w)

As the name of the main branch implies, this solution was crafted after thoroughly following the indications in the book, starting off
from the _Shameless Green_ initial draft.

[Link to the original ebook](https://sandimetz.com/99bottles)

## About the Book

"99 Bottles of OOP" is a practical guide to writing cost-effective, maintainable, and pleasing object-oriented code. The book uses the "99 Bottles of Beer" song as a code kata to demonstrate refactoring techniques and object-oriented design principles.
